Record your own screen and English narration. Keep the final cut below **3:00**. This file is a recording plan, not a claim that a video has been recorded or submitted.

| Time | Show | Explain |
|---|---|---|
| 0:00–0:08 | Real app, course page | “Before the event I had a private note-taking prototype. This week I built the standalone LessonTrace learning workflow shown here, including Meta tutoring and real Python execution.” |
| 0:08–0:25 | Open the original sample | Watching a tutorial can feel clear until you try the program yourself. This sample uses our own text and code. Prepared notes are labelled. |
| 0:25–0:45 | Predict and check the nested-loop output | A wrong expectation becomes a concrete learning signal; the exact code stays visible. |
| 0:45–1:05 | Coding task, failing starter, real trace | An extra outer break drops later rows. Show the failed cases, executed line and actual state. |
| 1:05–1:55 | Ask Meta with consent; **Live Meta calls** open | Show a real Muse Spark writer request and separate review request, response IDs and the resulting hint. Do not reveal the key. Ask for help on the observed bug, not a prewritten answer. |
| 1:55–2:25 | Apply the fix, run, step through | Remove the extra outer break. Python checks all three inputs, including empty rows. The model cannot award this pass. |
| 2:25–2:45 | Course and optional Hub support | Concept prerequisites keep unknown constructs out of tasks; consented research can deepen a weak topic. Label any prepared/replayed portion. |
| 2:45–2:57 | Repository and setup | A standalone public repo, own-key setup and keyless original sample. State the main limitation: small prototype, not proof of learning gains. |
